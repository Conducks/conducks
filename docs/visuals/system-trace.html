9 · The pattern

The same shape appears at every altitude. A stage computes a correct result, and the step that would make the result observable is missing — not broken, absent. Virtual induction has no persist call. bindNeuralCircuits has no index update. micro-pulse has no guard on its success message. guard has no branch for "no data". The fallbackAnalysis field has no writer. Each is one missing line, and each produces output that looks exactly like success.

That is why 660 passing tests coexisted with all of it: the tests assert that a stage ran, and every one of these stages does run. Nothing asserts that its output arrived — in the database, in the index, in the printed verdict. The single highest-value change on this page is not any individual fix; it is one test per stage that reads back what the stage claims to have written.
