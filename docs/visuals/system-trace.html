4

parse waves

single-threaded
500 units per wave → tree-sitter → spectrum → graph → flush → clear

Wave size is a constant, not adaptive. traced orchestrator.ts:123

The worker pool never spawns. isTs is __filename.endsWith('.ts'), which is false under compiled JS, so no installed copy can resolve a worker script. traced orchestrator.ts:24 · worker-pool.ts:16 · graph-engine.ts:44
Kernel timing on a full pulse: 15.96 s user + 5.41 s sys over 21.41 s wall ≈ 1.0 cores. measured /usr/bin/time -l, 30 Jul 2026
Regex fallback (reflectGnosis) runs when a grammar or query is missing. It captures a file node and little else, and it degrades rather than refuses — the pulse continues with a thin node instead of failing, which is why a missing grammar shows up as sparse edges rather than an error. traced reflector.ts:137, 156, 162
"82% of pulse time" withdrawn. It came from reading stage deltas in a memory trace, which ADR 0043 is entirely about not trusting. Parsing is the dominant stage; the percentage is not measured and is not asserted here.

The read paths

Three layers, deliberately separated by how much they must load. The docs layer takes no database connection at all, which is why it keeps working while a pulse holds the write lock.

docs layer

docs-status · docs-lint · bootstrap-docs · help · monitor

Reads authored markdown and the filesystem. No engine, no vault, no lock contention. traced ADR 0033

SQL layer

status counts · staleness · prune · taxonomy

Answers from the vault without materialising the graph, so a read-only session pays nothing for a graph it never walks. traced ADR 0038

graph layer

impact · trace · explain · rename · audit · flows

Must call ensureGraphLoaded() first. Four commands did not, and threw on every invocation until it was fixed. traced todo22

The pattern

Three separate features build correct results in memory and lose them at the same point: the pulse's final save() writes the pulse record and no rows, so anything added after the last wave flush is discarded. Cross-service binding was fixed by persisting its edges explicitly. Virtual induction and pulse circuits have the same shape and are still open.

None of this was visible from the test suite. 660 tests pass, and passed while all three produced nothing — because the tests assert that a stage ran, not that its output reached the database. That is the gap worth closing before anything else on the list.
