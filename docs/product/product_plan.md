## Core Product Vision

**The Synapse** — A living graph of the codebase. Nodes are symbols (functions, classes, variables). Edges are relationships (calls, imports, inherits). The graph is rebuilt deterministically on each pulse with full idempotency.

**The Mirror** — A real-time force-directed visual of the Synapse. Architectural layers cluster by gravity. High-risk symbols glow. Photon path tracing illuminates execution routes on click.

**The Agent Interface** — 9 MCP tools that give AI agents structural accuracy. `conducks_query`, `conducks_trace`, `conducks_impact`, `conducks_audit`, `conducks_metrics`, `conducks_evolution`, `conducks_system`, `conducks_link`, `conducks_explain`.

## Architectural Invariants

These never change regardless of feature additions:

1. Zero LLMs in the analysis pipeline. All scoring is deterministic and explainable.
2. Every score decomposes into its signals (Gravity, Complexity, Entropy, Churn, FanOut, Debt).
3. `pulseId` is always system-injected — agents never control which snapshot they read.
4. Synapse Core has zero external project dependencies.
5. MCP server is read-only. All writes go through the CLI `conducks analyze`.
